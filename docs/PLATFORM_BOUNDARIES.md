# Platform boundaries and alternatives

ControlSRE is deliberately not another all-in-one GRC system.

| Platform category | Primary strength | ControlSRE relationship |
|---|---|---|
| Managed compliance platforms | Fast program setup, integrations, workflows, auditor collaboration | Qualify evidence independently and observe automation reliability through authorized APIs |
| Cloud-native assessment services | Deep provider context and native evidence collection | Add cross-platform scope, period semantics, mapping, SLOs, and business impact |
| Open-source GRC systems | Flexible system of record, framework catalogs, self-hosting | Add runtime evidence observability, control reliability incidents, and economic boundaries |
| n8n and Zapier | Rapid workflow composition | Determine whether a successful execution produced a valid assurance outcome |
| SIEM and observability platforms | High-volume operational telemetry | Translate signals into period-scoped evidence and control consequences |
| CSPM and vulnerability platforms | Configuration and exposure findings | Connect findings to evidence validity, control state, audit obligations, and decisions |

Named platforms should be profiled only from primary documentation or authorized executions. Documentation can establish a capability, not a failure rate or comparative score.
