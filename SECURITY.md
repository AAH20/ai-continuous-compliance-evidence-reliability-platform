# Security policy

Do not submit secrets, access tokens, customer evidence, proprietary framework content, production identifiers, or personal data in a public issue.

Report a suspected vulnerability privately through GitHub Security Advisories for this repository. Include the affected version, impact, safe reproduction steps, and suggested mitigation when available.

The reference fixtures are synthetic. Production use requires threat modeling, tenant isolation, secret management, signed artifacts, least-privilege collectors, retention controls, audit logging, dependency scanning, and recovery exercises.

ControlSRE agents must treat evidence content as untrusted data. They cannot approve controls, accept risk, contact external parties, change production systems, or attribute commercial value without an explicit authorization boundary.
